### 🚀 Featured Projects

#### 1. 🔗 LinkPulse — Distributed URL Shortener

A backend-first URL shortener engineered for fast redirects and asynchronous click analytics.

**Key Features:**
- ⚡ Redis-cached redirects with PostgreSQL fallback.
- 📨 RabbitMQ-powered asynchronous analytics processing.
- 🔄 Idempotent workers with retries, backoff, and dead-letter queues.
- 🔐 Base62 short codes, custom aliases, expiration, and link deactivation.
- 🛡️ Privacy-conscious visitor tracking without storing raw IP addresses.
- 📊 React dashboard with analytics and admin telemetry.

**Tech Stack:** Node.js · Fastify · PostgreSQL · Redis · RabbitMQ · React · Docker Compose

🔎 **Source:** [GitHub – LinkPulse](https://github.com/iamSunnyrohit/LinkPulse)

---

#### 2. 🗳️ LivePoll — Real-Time Polling Platform

A real-time audience engagement platform built for interactive classrooms, workshops, presentations, and live events.

**Key Features:**
- ⚡ Instant vote synchronization using ASP.NET Core SignalR.
- 🔐 JWT authentication and BCrypt password hashing.
- 📱 QR-code room joining with unique six-character access codes.
- 🕵️ Anonymous polling and duplicate-vote protection.
- 📊 Live voting analytics and percentage distributions.
- 📁 CSV export for poll results and reports.
- 🗄️ SQLite persistence with Entity Framework Core.

**Tech Stack:** C# · ASP.NET Core 10 · React 19 · TypeScript · SignalR · SQLite · Entity Framework Core

🔎 **Source:** [GitHub – PollingApp](https://github.com/iamSunnyrohit/PollingApp)

---

#### 3. 🛡️ GateFlow — Python API Gateway

A developer-focused API Gateway built with FastAPI to explore microservices architecture, reverse proxying, and dynamic service routing.

**Key Features:**
- 🚦 Centralized API gateway for multiple microservices.
- 🔀 Dynamic route registration and management.
- ⚡ Asynchronous reverse proxy using HTTPX.
- 🐳 Docker Compose-based microservices orchestration.
- 🗄️ PostgreSQL-backed persistent route registry.
- 📡 Request metadata, latency tracking, and error handling.
- 🔧 React-based administration dashboard.

**Tech Stack:** Python · FastAPI · HTTPX · PostgreSQL · Docker · React

🔎 **Source:** [GitHub – GateFlow](https://github.com/iamSunnyrohit/GateFlow)
